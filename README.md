# Pão Caseiro da Claudia

Site catálogo da Pão Caseiro da Claudia — pães artesanais, bolos caseiros, tortas e salgados feitos com carinho.

## Estrutura

- `index.html` — página principal
- `styles.css` — estilos
- `script.js` — interações do cardápio, filtros, busca e montagem de pedido no WhatsApp
- `assets/` — logo e imagens
- `vercel.json` — configuração de deploy estático na Vercel

## Executar localmente

Como é um site estático, basta abrir o `index.html` ou servir a pasta com qualquer servidor HTTP:

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Deploy

O projeto está pronto para deploy na Vercel como site estático (sem etapa de build).
